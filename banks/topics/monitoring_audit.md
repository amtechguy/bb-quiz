**21.** If a customer needs to audit the change management of AWS resources, which of the following AWS services should the customer NOT use?
- A. AWS Trusted Advisor. ✅
- B. AWS Config.
- C. Amazon CloudWatch.
- D. Amazon CloudTrail
**Explanation:** AWS Trusted Advisor provides best practice recommendations but does not track resource changes. AWS Config, CloudWatch, and CloudTrail all provide change tracking and audit capabilities for AWS resources.

**22.** Which AWS service provides a customized view of the health of specific AWS services that power a customer's workloads?
- A. Amazon CloudWatch.
- B. AWS Service Health Dashboard.
- C. AWS Personal Health Dashboard. ✅
- D. AWS X-Ray.
**Explanation:** AWS Personal Health Dashboard gives you a personalized view of AWS service health events that may affect your specific resources, unlike the Service Health Dashboard which shows general AWS-wide status.

**25.** What AWS service would be used to centrally manage AWS access policies across multiple accounts?
